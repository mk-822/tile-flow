遊び方

  1. 受け止める

    左右キーでパドルを動かし、ベルトの端から落ちてくるタイルを受け止めます。左右キーは押し続けると連続で移動します。↓キーを押している間、ベルト上の全タイルが加速し、奥から新しいタイルが出てくる間隔も短くなります。パドルには5枚まで載せられます。

  2. そろえる

    Spaceで一番上のタイルを同じ列のプールへ落とし、下から積み上げます。同じ色を縦・横・斜めに3枚以上並べると消え、上のタイルが落ちて連鎖します。消去演出中もタイルを置いて連鎖を狙えます。光っている縦列に同色を足すと、4枚・5枚まとめて消せます。

  3. 次のウェーブへ

    5ウェーブごとのクリア後は、左右で次のWAVEか、5・10ウェーブ先を選べます。選択に応じてドロップ枠が3・4・5枚に回復し、スキップ先のクリアでボーナスを獲得できます。ドロップ枠を使い切るとゲーム終了です。↑キーで一番上のタイルをベルトに返せます。

  4. タッチ操作

    左右ボタンを長押しするか、左右にスワイプして指を止めると、パドルが同じ方向にリピート移動します。パドルラインをタップすると、その列まで移動します。プールをタップすると落とし、ベルトをタップすると投げ返します。盤面まわりの余白を長押しすると早送りします。

  5. ゲームパッド

    十字キーの左右か左スティックでパドルを動かします。下側のボタン（A / ×）で決定・タイルを落とす、上側のボタン（Y / △）か十字キーの↑で投げ返す、RT / R2 か十字キーの↓の長押しで早送り、Start / Options で一時停止・再開します。

  6. 難易度と開始WAVE

    左右で初級・中級・上級、上下でWAVE 1・6・11を選びます。難易度が高いほどタイルが速く流れ、色の種類も増えます。ベストスコアは難易度ごとに保存されます。
